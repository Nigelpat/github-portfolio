# Classroom prototype source excerpts

HTML, CSS and JavaScript files from the supplied Community Garden team project archive `garden mangament (5).rar`, plus the supplied SQL schema. The `.txt` extensions are intentional: these files are provided as readable source, not a publicly running login/payment application. The default demonstration manager password and address have been replaced in `script.js.txt`; the test-account README is excluded.

The historical prototype relies on browser localStorage and does not implement secure authentication, server-side authorization, or real payments. The SQL schema is an educational design, not a production database: do not store plaintext passwords or payment card numbers. Do not enter real personal or payment information into this prototype.

Team project, CPSC 4360 Software Engineering, Spring 2026. Patrick Nanlohy served as documentation lead. Shared team materials should only be published with the team's and course's permission.
