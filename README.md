## Run locally
From the repository root, run `python -m http.server 8000` and visit http://localhost:8000. Run the classifier tests with `node ai-assistant/test.js`. No dependencies or API keys required.

## Development and limitations
Career Coach AI uses a small supervised naive Bayes classifier and curated responses, not an external language model. ChatGPT assisted with implementation, writing and test generation. The academic project case study now includes original screenshots, diagrams, and readable source excerpts from the Community Garden team project. The historical prototype is not deployed as a live login/payment app. Focus Board is a new AI-assisted prototype. See the AI project documentation and AI prompt log in `docs/`.
